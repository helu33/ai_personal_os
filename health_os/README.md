# 健康 OS

个人健康信息与追踪工作区，由「健康导师」（示例角色）维护。

全局规则见仓库根目录 `AGENTS.md`。真实身体数据、日志和计划请留在私有处，不要公开。

## 结构

- `profile.template.md` — 复制为 `profile.md` 后填写基础档案（宜私有）
- `lifestyle.template.md` — 复制为 `lifestyle.md` 后写作成息、运动、饮食现状
- `metrics/` — 体重等可量化指标
- `logs/` — 日常追踪日志
- `plans/` — 阶段性建议与计划
- `plans/daily/` — 当日训练与饮食待办

本模板不附带任何真实健康记录。
