# 错题

按课程分文件。以后有新课程再加文件。

## 格式

每个文件按章节分节。章节号或章节名没报就写「章节未报」，可在括号里写已知主题，不要编造章节号。

### 题号（册/页）（状态）
- 题目要点：一句话（截图须转成文字，不只存图片）
- 错因：用户口述；没说就先问一句，不猜
- 正确思路：只写关键一步
- 记录：MM-DD 做错；可多行。没报日期写「做错日期未报」

## 状态

只有三种，按这个方向推进：待重做 → 重做对1次 → 已掌握。
用户说重做对了就往前推一档；又错了就退回「待重做」，并在「记录」里加一行日期。

同目录的 `示例课程.md` 是虚构示范，不是真实错题。
