# Personal OS

个人成长档案：用 Markdown 管理目标、学习、项目与复盘，并配合 `../core/` 得到可执行的晨报和任务。

全局规则见仓库根目录 `AGENTS.md`。本目录职责见 `AGENTS.md`。

## 仓库地图

| 目录 | 用途 |
|------|------|
| `00_Profile/` | 个人信息、性格、学习方式（改前需确认；宜私有） |
| `01_Goals/` | 长期与阶段目标（改前需确认；宜私有） |
| `02_Strategy/` | 路线与决策原则（改前需确认；宜私有） |
| `03_Learning/` | 学习路线与阶段进度；错题在 `错题/` |
| `04_Project/` | 项目笔记 |
| `05_Daily/` | 每日归档 |
| `06_Review/` | 周复盘 |
| `07_Ideas/` | 想法池 |
| `08_Decision/` | 决策记录 |
| `09_Knowledge/` | 可复用知识沉淀（含章末总结） |

前端在同级目录 `../core/`（`today_task.md`、`state.md`、`inbox.md`），由 jason（示例角色）写。用户日常不必打开仓库。

## 与 jason 的协作节奏

用户只聊天口述：晚上交给 jason 三行和明天计划，早上看晨报。不必自己写日报，也不必打开仓库填 `today_task`。

晨间与周日流程见根目录 `AGENTS.md` 第 4 节。时间均为示例，请改成你的作息。
