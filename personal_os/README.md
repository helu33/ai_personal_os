# 成长档案（personal_os）

个人成长档案：用 Markdown 管理目标、学习、项目与复盘，并配合 `../core/` 得到可执行的晨报和任务。面向学生的整体生活改进，一次只抓一个改善方向。

全局规则见仓库根目录 `AGENTS.md`。本目录职责见 `AGENTS.md`。给使用者看的上手说明见 [`新手指引.md`](新手指引.md)。

## 仓库地图

| 目录 | 用途 |
|------|------|
| `新手指引.md` | 给使用者看的上手说明 |
| `00_Profile/` | 个人信息、性格、学习方式；入门档案模板在此（改前需确认；宜私有） |
| `01_Goals/` | 长期与阶段目标（改前需确认；宜私有） |
| `02_Strategy/` | 路线与决策原则（改前需确认；宜私有） |
| `03_Learning/` | 学习路线与阶段进度；错题在 `错题/` |
| `04_Project/` | 项目笔记 |
| `05_Daily/` | 每日归档 |
| `06_Review/` | 周复盘 |
| `07_Ideas/` | 想法池 |
| `08_Decision/` | 决策记录 |
| `09_Knowledge/` | 可复用知识沉淀（含章末总结） |

前端在同级目录 `../core/`（`today_task.md`、`state.md`、`inbox.md`），由 jason（示例角色）写。用户日常不必打开仓库。

## 与 jason 的协作节奏

用户只聊天口述：晚上交给 jason 复盘（硬块完成、花费、心情与心得、明天安排），早上看简报。不必自己写日报，也不必打开仓库填 `today_task`。

晨间与周日流程见根目录 `AGENTS.md` 第 6 节。提醒时间和作息红线均由使用者自定，不要沿用任何钟点。第一周建议只跑晚间复盘 + 一块硬块。
